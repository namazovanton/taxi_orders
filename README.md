# Сервис заказа такси

---
## Описание проекта
Для привлечения большего количества водителей в период пиковой нагрузки, нужно спрогнозировать количество заказов такси на следующий час. Необходимо построить модель для такого предсказания. 

---
## Цель исследования
Построить модель, определяющую количество заказов такси на следующий час.

---
## Библиотеки
```javascript
- Pandas
- Lightgbm
- Catboost
- DecisionTreeRegressor
- LinearRegression
- Numpy
- Matplotlib
- Sklearn
- GridSearchCV
- Category_encoders
- Statsmodels
```

---
## Набор данных
В распоряжении набор исторических данных о заказах такси в аэропортах.
```javascript
datetime – дата и время.
num_orders – количество заказов.
```
